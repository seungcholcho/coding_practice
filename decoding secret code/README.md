## 문제 요약

1 ~ n 중 서로 다른 정수 5개로 된 비밀 코드가 있다. m번 시도마다 5개를 입력하면 그중 비밀 코드에 들어 있는 개수를 알려준다. 시도 결과와 모두 맞는 비밀 코드 후보의 개수를 구한다.

- 10 ≤ n ≤ 30
- 1 ≤ m ≤ 10

---

## 풀이

### 경우의 수부터

| 1차 계산 | 구멍 |
|---|---|
| `15 × 14 × 13 × 12 × 11` | n 최대값은 30, 그리고 이건 **순서 있게** 고른 수 |
| `(30 × 29 × 28 × 27 × 26) / 5!` = **142,506** | 비밀 코드는 정렬되어 있으니 순서 없이 → 5!로 나눔 ✓ |

142,506 × 시도 10 × 교집합 약 5 ≈ **700만 번** → 10^7 안쪽이라 브루트포스 가능.
(실제로 최대 입력에서 약 0.15초)

### 방법

1. 5중 반복으로 1 ~ n 중 5개 조합을 전부 만든다. 각 반복의 시작을 앞 숫자 + 1로 두면 자동으로 오름차순, 중복 없음.
2. 비밀번호마다 시도를 전부 확인한다. `len(시도 & 비밀번호)`가 응답과 다르면 바로 탈락(`break`).
3. 모든 시도를 통과한 비밀번호 개수를 센다.

### 코드

```python
def solution(n, q, ans):
    q_sets = [set(x) for x in q]

    passcode_sets = []
    for a in range(1, n - 3):
        for b in range(a + 1, n - 2):
            for c in range(b + 1, n - 1):
                for d in range(c + 1, n):
                    for e in range(d + 1, n + 1):
                        passcode_sets.append({a, b, c, d, e})

    count = 0
    for passcode in passcode_sets:
        trials = 0
        for i in range(len(q_sets)):
            if len(q_sets[i] & passcode) != ans[i]:
                break                       # 탈락, 다음 비밀번호로
            trials += 1
        if trials == len(q_sets):           # m개 전부 통과
            count += 1
    return count
```

(제출 코드에서 정리한 것: 반복 변수 `q`가 매개변수 `q`와 이름이 겹쳐서 `a ~ e`로 바꿈. 제출 코드는 `q_sets`를 먼저 만들어둬서 우연히 문제가 없었다. `elif` 대신 `break` 다음 줄로 정리. 동작은 같음.)

## 회고

### 지난주보다 빨라진 점

새 문제를 **혼자 1시간 반**에 풀었다. 시작하자마자 경우의 수와 시간부터 계산하는 습관이 자리 잡았다.

### 막혔던 것

- **경우의 수:** n의 최대값 대신 15를 넣음, 순서 있는 개수로 셈 → 순서 없는 조합은 5!로 나눈다.
- **`break`의 범위:** 시도 반복 바깥에서 비밀번호를 돌다가 `break`하니 반복 전체가 끝남. 반복 순서를 "비밀번호마다 → 시도마다"로 바꿔서 해결.
- **후보가 쌓이기만 함:** 시도마다 맞는 비밀번호를 같은 set에 계속 넣으니 "어느 한 시도에라도 맞는 것"이 됨.
- **`while`로 인덱스 직접 관리:** `ans[i]`에 비밀번호 번호를 씀(인덱스 혼동), 다 맞은 뒤 `i`를 안 올려 무한 반복, `<=` 범위 → `for` 두 겹으로 바꾸니 전부 사라짐.
- **하나 차이:** "전부 맞음" 기준을 `len - 1`로 씀 → m = 1에서 아무것도 안 셈.

### 처음 써본 것 / 다시 확인한 것

- set: 중복 없음, 순서 없음(인덱스 X), `in` 빠름, `&` `|` `-` `^`, `len(a & b)`
- set 안에는 set·리스트를 못 넣음 → `frozenset`이나 튜플
- 빈 set은 `set()`, `{}`는 빈 dict
- `continue`는 이번 바퀴만 건너뜀, `break`는 가장 안쪽 반복을 끝냄
- `while` 조건 안에서 반복: `any(...)`, `all(...)`
