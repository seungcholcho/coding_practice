## 문제 요약

0시부터 23시까지 시간대별 이용자 수가 주어진다. 이용자가 m명 늘어날 때마다 서버 1대가 더 필요하고(n × m명 이상 (n + 1) × m명 미만이면 n대), 증설한 서버는 k시간 동안 운영된 뒤 반납된다. 모든 이용자를 감당하기 위한 최소 증설 횟수를 구한다.

- players 길이 24, 원소 0 ~ 1,000
- 1 ≤ m ≤ 1,000, 1 ≤ k ≤ 24

---

## 풀이

### 핵심: 지금 운영 중인 서버로 감당 가능한 최대 이용자

서버가 s대면 감당 가능한 이용자는 **s × m + (m - 1)명까지**다. 서버가 0대여도 m - 1명까지는 증설이 필요 없기 때문.

그래서 수용량을 `m - 1`에서 시작해, 운영 중인 서버 한 대마다 m씩 더한다.

### 시간마다

1. **운영 중인 서버 세기:** `time - k + 1`시부터 `time`시까지 증설한 서버가 지금 운영 중이다. (그보다 앞에 증설한 건 이미 반납)
2. **모자라면 모자란 만큼만 증설:** 이용자가 수용량보다 많으면, `ceil((이용자 - 수용량) / m)`대를 이번 시간에 증설한다.
3. 마지막에 증설한 서버를 모두 더한다.

### 시간

24시간 × 최대 24시간 창 = 576번. 아주 작다.

### 코드

```python
import math

def solution(players, m, k):
    servers_added = [0] * 24                    # 시간마다 증설한 서버 수
    for time in range(24):
        server_capacity = m - 1                 # 서버 0대여도 m - 1명까지 OK
        for i in range(time - k + 1, time + 1): # 지금 운영 중인 서버
            if i >= 0:
                server_capacity += servers_added[i] * m
        if server_capacity < players[time]:     # 모자라면 모자란 만큼만
            servers_added[time] = math.ceil((players[time] - server_capacity) / m)
    return sum(servers_added)
```

(제출한 코드에서 쓰이지 않는 `server_capacity = m-1` 재설정 줄을 지우고, `if i < 0: pass / else:`를 `if i >= 0:`으로 줄임. 동작은 같음.)

## 회고

### 지금까지 중 가장 빨랐다

새 문제를 처음으로 **도움 없이 1시간 30분**에 풀었다. 지난주 문제들은 4~5시간씩 걸렸다.

### 막혔던 것

- 처음엔 서버를 `[?, ?, 남은 시간]`으로 덱에 넣고, 반복 중에 `popleft()`로 빼려다가 꼬였다. (반복 중에 같은 컨테이너를 바꾸면 원소를 건너뛰거나 범위 밖 에러, 확인한 원소와 뺀 원소가 다름)
- 서버 객체를 들고 다니는 대신, **시간마다 증설한 대수만 기록하고 지난 k시간을 더하는** 방식으로 바꾸니 단순해졌다.

### 처음 써본 것 / 다시 확인한 것

- `math.ceil` (무조건 올림), `math.floor` (무조건 내림)
- `round`는 .5일 때 짝수로 보낸다: `round(2.5) = 2`
- 정수끼리 올림: `-(-a // b)` (소수 오차 없음)
- VS Code 찾기 및 바꾸기: 맥 `Cmd + Option + F`, 줄 주석 `Cmd + /`
